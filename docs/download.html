MAC の初回起動

「マルウェアが含まれていないことを検証できません」と表示されたら

Mac 版はアプリ内部の整合性のためにアドホック署名していますが、Apple Developer ID 署名・公証はしていません。公式のダウンロードリンクから入手したアプリを開く場合は、次の手順で個別に許可できます。

  1. DMG からインストール

    ダウンロードした DMG を開き、「Animals Desktop - for Real」を「アプリケーション」フォルダへドラッグします。

  2. アプリを一度開く

    「アプリケーション」フォルダからアプリを開きます。警告が出たらダイアログを閉じます。

  3. 設定の「このまま開く」を選ぶ

    macOS 13 以降Apple メニュー →「システム設定」→「プライバシーとセキュリティ」。下部の「セキュリティ」までスクロールし、このアプリの「このまま開く」を選びます。

    macOS 12 MontereyApple メニュー →「システム環境設定」→「セキュリティとプライバシー」→「一般」→「このまま開く」を選びます。

  4. 確認して開く

    確認ダイアログでも「このまま開く」または「開く」を選びます。認証が必要な場合は、Mac 上で管理者名とパスワードを入力してください。

起動後はメニューバーへ。画面上部の肉球アイコンから「今すぐ表示」や設定を選べます。Dock にアイコンは表示されません。

「このまま開く」が見つからない場合は、アプリをもう一度開こうとしてから設定画面に戻ってください。

「壊れているため開けません」は別のエラーです。最新版の DMG をダウンロードし直して入れ替えてください。続く場合は GitHub Issues でお知らせください。

Mac の種類が分からないとき

画面左上の Apple メニューから「この Mac について」を開き、「チップ」または「プロセッサ」を確認してください。Intel と表示されれば Intel Mac 版、M1 などと表示されれば M1 以降の Mac 版を選びます。

Windows のインストール

ダウンロードした EXE を実行して画面の案内に従ってください。インストールせずに使う場合は ZIP 形式を選べます。

更新履歴・過去の版・その他の形式は GitHub Releases をご覧ください。
