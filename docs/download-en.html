FIRST LAUNCH ON MAC

If Apple cannot check the app for malicious software

The Mac app is ad hoc signed for internal bundle integrity, but it has no Apple Developer ID signature or notarization. If you downloaded it from the official links on this page, you can allow this app with these steps.

  1. Install from the DMG

    Open the downloaded DMG and drag “Animals Desktop - for Real” to Applications.

  2. Try opening the app once

    Open it from Applications. If a warning appears, close the alert.

  3. Choose Open Anyway in settings

    macOS 13 or laterApple menu → System Settings → Privacy & Security. Scroll down to Security and choose Open Anyway for this app.

    macOS 12 MontereyApple menu → System Preferences → Security & Privacy → General → Open Anyway.

  4. Confirm and open

    Choose Open Anyway or Open in the next dialog. If authentication is required, enter your Mac administrator name and password on your Mac.

After launch, look in the menu bar. Use the paw icon at the top of the screen for Show now and settings. The app does not show an icon in the Dock.

If Open Anyway is missing, try opening the app again as in step 2, then return to settings.

“The app is damaged” is a different error. Download the latest DMG again and replace the old app. If it persists, report it in GitHub Issues.

Read Apple’s instructions ↗

Which Mac do I have?

Open the Apple menu and choose “About This Mac.” Check “Chip” or “Processor.” Choose the Intel download if you see Intel, or the Apple Silicon download if you see M1 or a later M-series chip.

Install on Windows

Run the downloaded EXE and follow the setup steps. Choose the ZIP if you want to use it without an installer.

For older versions and other formats, see GitHub Releases.
