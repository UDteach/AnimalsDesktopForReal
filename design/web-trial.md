# Webでおためし

公式サイトからインストールなしで動物を見て、必要なら全画面にする。OBS設定を知らなくても使える入口とする。

- 導線: トップの最初のボタン、スマホでも見えるナビ、ダウンロード前の案内から `try/` へ。英語は `try/?lang=en`。
- 画面: 既存サイトの生成り・茶色を継承。大きな表示面、上端の「今すぐ表示 / 一時停止 / 全画面にする」、下の動物・毛色・間隔・サイズ・背景の簡単な設定。
- 採用: 表示面を主役とする専用ページ。OBS編集画面の流用は初回の項目数が多く、トップの小さなプレビュー拡張だけではURLで直接開けないため採用しない。
- 全画面: ユーザー操作でFullscreen APIを呼ぶ。非対応・拒否時はページ内拡大。戻る操作を常に用意し、Esc、タップ、キーボードで復帰できる。操作しない間は全画面の操作部を隠す。
- 再生: 既存の `createPlayback` と公開素材を共用。ページ内表示のみ。別タブ・ページ離脱時は停止し、手動停止の意思を保ったまま復帰する。
- 保存: おためしの選択は独立したブラウザ保存キーを使う。OBSの下書きを変更しない。壊れた値・保存拒否でも初期値で操作できる。
- コピー: 日本語は短い動作名。登録や導入手順を挟まない。デスクトップに重ねる機能はアプリへの案内で説明する。
- 確認: デスクトップと320/390px幅、入口から再生・設定・全画面・解除、非対応時の拡大、動画失敗時の画像、停止と再開、既存OBSと生成物検査。

実装とブラウザでの確認結果は [qa/web-trial/results.md](../qa/web-trial/results.md) に記録。未解決の表示差はない。モバイル実機と公開環境は未確認。
APIの参照: [MDN requestFullscreen](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen)、[MDN fullscreenEnabled](https://developer.mozilla.org/en-US/docs/Web/API/Document/fullscreenEnabled)。
