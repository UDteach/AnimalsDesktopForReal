# Webでおためし 確認結果

実施日: 2026-09-27。基準コミット: `1f0fb8f`。作業ブランチ: `codex/web-trial`。以下は公開前の実装確認の記録。
環境: macOS、Node.js v24.15.0、Playwright Chromium、ローカルHTTP `http://localhost:4173/`。

| 確認 | 結果 |
| --- | --- |
| 日本語・英語トップ / ダウンロードの導線 | 4ページとも320px幅でヘッダーの体験リンクが見え、クリックで対応言語のおためしへ遷移して動物が再生された。トップの主ボタン、ダウンロード冒頭の案内も同じURL。 |
| 表示と操作 | 1440 / 390 / 320px幅で横スクロールなし。動物・毛色の選択、サイズ・間隔・背景の変更、今すぐ表示、一時停止・再開を確認。320pxのボタン改行を修正した。 |
| 全画面 | ネイティブFullscreen APIで表示・退出を確認。3.5秒後の操作部非表示と、マウス・Tabでの復帰を確認。退出後に設定のキーボード操作が戻ることを確認。 |
| 全画面非対応 / 拒否 | 非対応フラグとAPI拒否を注入。ページ内拡大に切り替わり、ボタンとEscで戻れる。拡大中は画面外の操作部がinertになる。 |
| 選択の保存 | 再読み込み後に種・毛色が戻る。壊れたJSONは初期値に復帰。Storage APIが読み書きとも例外を投げる状態でも再生・設定変更できる。 |
| タブの表示状態と停止 | visibilitychangeを模擬して停止・復帰を確認。手動一時停止は表示復帰や設定変更で解除されない。 |
| 動きを減らす設定 | prefers-reduced-motionを有効にすると停止状態で開く。「今すぐ表示」から明示的に再生できる。 |
| 動画404 | 同じ毛色のPNGに切り替わり、画像での表示であることを案内。通信回復後は動画を再生。 |
| 動画・PNG両方404 | 読み込み失敗と再試行の案内を表示。次の出現時刻を維持し、通信回復後に自動再生できる。共有runtimeが通常再生の終了結果を捨てていた箇所を修正した。 |
| OBS回帰 | 既存設定ページのプレビューと発行URLの再生を確認。表示専用ページの背景は `rgba(0, 0, 0, 0)`。 |
| 自動チェック | `npm run check:obs` の8テスト、`npm run check` の12テストと全素材検査が合格。`node --check web/try/trial.mjs`、生成物一致・参照先検査、`git diff --check` も合格。 |
| エラー | 通常操作のページエラー0件。404を注入した確認時のネットワークエラーのみ発生。 |

画像: [デスクトップ](desktop.png)、[390px](mobile.png)、[320px](mobile-320.png)、[全画面](fullscreen.png)、[トップ](home-desktop.png)、[トップ320px](home-mobile.png)、[ダウンロード320px](download-mobile.png)。全画面の案内は動物と重ならない上側へ配置し、修正後に再撮影した。

コピー確認: 日本語は短い操作名、既存サイトの丁寧な距離感、説明は1〜2文、主導線の語は「Webでおためし」、ブラウザとデスクトップアプリの表示範囲を明示する。内部実装用語を表示しない。英語も同じ操作順で確認した。
