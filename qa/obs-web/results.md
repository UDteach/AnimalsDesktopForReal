# OBS向けWeb版 QA結果

実施日: 2026-09-27（JST）
基準コミット: `60a6809`、作業ブランチ: `codex/obs-web`
環境: macOS arm64、Node.js v24.15.0、Headless Chromium 153、ローカルHTTP（`docs/` を配信）

## 合格した確認

| 対象 | 結果 |
| --- | --- |
| 設定・URL・抽選 | `npm run check:obs` の8テストが合格。全16毛色×4動作のカタログ、設定の往復変換、最大URL長、異常入力、抽選・継承・間隔を検証した。 |
| 既存アプリと公開素材 | `npm run check` の12テストと素材参照検査が合格。64本の公開WebMの開始・2秒地点に透明画素、16枚のPNGに透明画素があることを確認した。 |
| 設定画面 | 日本語とEnglishの表示、選択0件時のURL発行停止、1毛色選択後のURL発行、プリセット保存と再読み込み後の復元、390 px幅で横スクロールがないことをChromiumで確認した。 |
| 生成URLからの表示 | 設定画面で発行したURLを表示ページで開き、選択した1毛色のみが再生候補になること、表示ページに設定UIや文字がなく背景が透明であることを確認した。 |
| 動画・代替画像 | Chromiumで透過WebMを再生し、フレームの透明画素を確認した。動画URLを404にした場合、同じ動物の透過PNGに切り替わることを確認した。 |
| 異常URL | 壊れた設定URLでは透明のまま停止し、可視状態イベントを送っても再生しないことを確認した。正常URLから異常URLへの切り替えでも同様。 |
